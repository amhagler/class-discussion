        Discussion Tracker
        How to Use
        Setup
        1. Enter a title and optional discussion question.
        2. Press Enter from the title, question, or educator field to move into participant entry. Use Shift+Enter for a question line break.
        3. Add an optional educator name if you want yourself/facilitator included as a distinct pill.
        4. Leave Include in stats unchecked to keep educator airtime out of student balance data.
        5. Choose whether to use contribution tags, then pick or edit a local tag set before starting.
        6. The educator uses hotkey B, sits clearly below the circle, and can be hidden or shown from the top bar.
        7. Add student participants, then click Done.
        During Discussion
        • Click a pill when someone starts speaking. Clicking the same active pill, or Pause, ends the current segment.
        • Choose a 1-5 rating, optional tags, and an optional comment, then Save.
        • Use Mark Moment, or press Z when you are not typing, to capture a notable moment without stopping the current speaker timer.
        • Use the Tags button to switch or edit tag sets. Changes affect future entries only.
        • Use Undo Last if you clicked the wrong speaker or made a recent setup/arrange change.
        • Press / to open or close the discussion log quickly.
        • In the log, click a participant name to move that entry to a different owner. Ratings, comments, tags, duration, stats, and discussion-flow lines update with it.
        • Alt+Shift plus a participant hotkey opens notes for that person. Alt+Shift+B opens educator notes when the educator is visible.
        • The Live Stats panel shows time, current speaker duration, class average, balance, top contributors, and who has not spoken yet.
        • The Recent Review section below Live Stats shows the last three logged contributions, so you can quickly catch mistaken owners, ratings, or comments.
        • Use the Review button in Live Stats to show or hide Recent Review.
        • Edit owner, rating, or comment directly in Recent Review, or click the row label to jump to that row in the discussion log.
        • Stats can be compacted, hidden, or shown again without affecting the discussion data.
        • Screenshot / Snip opens the system snipping workflow when available. On Mac, use Command+Shift+4.
        Moment Marker
        • Mark Moment is available during a live discussion from the top bar, or with the Z key when your cursor is not in a text field.
        • Moment types use number keys inside the marker box: 1 Key Insight, 2 Discussion Craft, 3 Wrong Turn, and 4 Tension Point.
        • Use an optional comment to describe what happened. Ctrl+Enter saves, and Escape cancels.
        • Moment rows are highlighted in the discussion log with the secondary color.
        • Marked moments do not add speaking time, change ratings, affect averages, create connection lines, or count toward the leaderboard.
        Arrange Mode
        • Arrange Mode turns off speaker-recording clicks and participant hotkeys.
        • Free Drag lets you approximate classroom seating. Ring Order lets you reorder students by dragging them around the circle.
        • Use Snap Circle in the top bar to return everyone to the clean circle layout.
        • Arrange Mode remains available after End, and arranging preserves counts, notes, ratings, timings, and connections.
        After End
        • Replay controls appear after ending the discussion, and participant counts tick upward during replay.
        • The report generates automatically when you end the discussion.
        • The Live Stats panel switches to a domination leaderboard. The class discussion average can be shown or hidden after End.
        • Balance remains visible below the leaderboard.
        • The report summarizes ratings, airtime, domination percentage, tags, and notes.
        • Copy Log, Copy Report, or Copy Both to save the discussion outside the browser.
        • Copy Both appears once the report has been generated.
        • Live-only controls such as Undo, Help, and Participants disappear after End.
        Recovery and Privacy
        • The current discussion is autosaved locally in this browser.
        • If Chrome updates, crashes, or refreshes, the tracker offers recovery on reload.
        • Use Restart only after copying or saving what you need.
        • No account is used.
        • No student data is sent to a server by this page.
        • Autosave lives only in this browser's local storage, with a tab-only fallback if needed.
